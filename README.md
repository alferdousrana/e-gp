# দরপত্র পাঠশালা — e-GP শেখার মোবাইল অ্যাপ

৭ সপ্তাহে ধাপে ধাপে e-GP ও সরকারি দরপত্রে পেশাদার হওয়ার জন্য HTML, CSS ও JavaScript-এ তৈরি অ্যাপ। কোনো build বা সার্ভার লাগে না।

## যা আছে
- ৭ সপ্তাহ, ২৫টি পাঠ — প্রতিটিতে ব্যাখ্যা, বাস্তব উদাহরণ (নীলাকাশ সফটটেকের গল্প), পরিভাষা, “একটু ভাবো” প্রশ্ন
- প্রতিটি পাঠ শেষে MCQ কুইজ ও সংক্ষিপ্ত প্রশ্ন (মূল ধারণা মিলিয়ে মূল্যায়ন + আদর্শ উত্তর)
- XP, ৮টি স্তর, টানা দিনের ধারা, দৈনিক লক্ষ্য, ১৮টি ব্যাজ, কনফেটি ও শব্দ
- অনুশীলন: দৈনিক চ্যালেঞ্জ, ফ্ল্যাশকার্ড, মিলাও খেলা, ভুলের খাতা, পরিভাষা অভিধান
- টুলস: Tender Analysis Sheet, Bid/No-Bid বিশ্লেষক, সাবমিশন চেকলিস্ট
- চূড়ান্ত ব্যবহারিক পরীক্ষা (অদেখা দরপত্র) ও প্রিন্টযোগ্য সনদ
- অগ্রগতি ফোনের ব্রাউজারে সংরক্ষিত থাকে; ব্যাকআপ নামানো/ফেরানো যায়
- PWA: ফোনে “Add to Home screen” করলে অ্যাপের মতো খোলে, অফলাইনেও চলে

## GitHub Pages-এ deploy
1. GitHub-এ নতুন repository বানাও (যেমন `egp-pathshala`), Public রাখো।
2. এই ফোল্ডারের সব ফাইল (`.nojekyll` সহ) repository-র মূল জায়গায় upload করো।
3. Settings → Pages → Source: “Deploy from a branch”, Branch: `main`, ফোল্ডার `/ (root)` → Save।
4. এক-দুই মিনিট পর ঠিকানা: `https://<তোমার-username>.github.io/egp-pathshala/`
5. ফোনে Chrome-এ খুলে মেনু → “Add to Home screen”।

## কন্টেন্ট বদলানো
- পাঠগুলো `js/content/week1.js` … `week7.js` ফাইলে।
- কন্টেন্ট বদলানোর পর `sw.js`-এ `VERSION` বাড়িয়ে দাও (`v1` → `v2`), নইলে পুরনো ক্যাশ দেখাতে পারে।
